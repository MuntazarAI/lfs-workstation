# Documentation

This directory contains the practical build record for the LFS Workstation project.

## Documents

- [Build log](build-log.md) — verified package versions, configuration choices, and installation checks.
- [Troubleshooting](troubleshooting.md) — problems encountered and the fixes confirmed to work.

## Documentation rules

- Record only commands and outcomes that were actually verified.
- Keep package-specific instructions aligned with the matching LFS/BLFS book.
- Do not store passwords, access tokens, private keys, or personal data here.
- If a test fails or is skipped, record that accurately instead of describing the package as fully tested.
